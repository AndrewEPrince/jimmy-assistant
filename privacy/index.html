Privacy Policy

Last updated: October 13, 2026

Overview

Jimmy Assistant is a privately operated, self-hosted AI assistant designed to help with scheduling, reminders, and planning.

Google Data Access

With authorization, Jimmy Assistant accesses Google Calendar events using the read-only Google Calendar API permission. This may include event titles, dates, times, descriptions, locations, and other calendar details returned by Google. Basic Google account identification is used to identify the connected account.

How Information Is Used

Calendar information is used to display upcoming events, summarize schedules, identify scheduling conflicts, and help plan activities. The current Google Calendar integration does not create, modify, or delete calendar events.

Storage and Security

Jimmy operates on a privately managed computer. Google OAuth credentials are stored locally using the gog credential storage system. Calendar information may appear in local assistant session histories, logs, or planning records. Access to the computer and its credentials is restricted by local security controls.

AI Processing and Sharing

Relevant calendar information may be sent to external AI API providers, including OpenAI and Anthropic, when needed to generate summaries or planning recommendations. Such processing is subject to their applicable API data policies.

Google user data is not sold, used for advertising, or used by Jimmy Assistant to train general-purpose AI models.

Data Retention and Deletion

Locally stored credentials remain until removed or revoked. Calendar information included in assistant histories or planning records may remain until those local records are deleted. Access can be revoked through Google Account's third-party connection settings. Local records and credentials can be deleted by the application's operator.

Changes

This policy will be updated when Jimmy's Google data access or processing practices materially change.
